# v1.0.2 - Quality Gate Hardening and Agent Workflow Expansion

## Summary

This release formalizes strict local and CI quality gates, enforces non-Markdown line-length at 140 characters, expands lint/formatter coverage, modernizes CI and test container tooling, and adds complete Copilot agent/skill scaffolding for reliable maintenance workflows.

Commit baseline documented in this file: fe94e2e (amended after this document is added).

## Key Changes

### 1. Mandatory lint and formatter gates

- Expanded unified quality gate in tests/run_tests.sh with:
  - ShellCheck
  - shfmt (check mode)
  - yamllint
  - markdownlint-cli (Markdown line-length excluded by policy)
  - hadolint
  - actionlint
  - JSON manifest validation
  - custom non-Markdown max line-length checker (140 chars)
- Added/updated lint config files:
  - .editorconfig
  - .hadolint.yaml
  - .markdownlint.json
  - .shfmt.conf
  - .yamllint

### 2. CI hardening and dependency pinning

- Updated .github/workflows/test.yml to enforce quality gates in CI and improve shell quoting/robustness.
- Added .github/dependabot.yml to keep GitHub Actions and Docker dependencies updated.
- Modernized tests/Dockerfile with pinned toolchain/runtime versions used by lint and tests.

### 3. Local pipeline reliability

- Updated scripts/run_local_tests.ps1 to fail fast on each stage and improve local parity.
- Updated scripts/run_coverage.ps1 and tests/transform_coverage.py for consistent coverage artifact generation and badge updates.

### 4. Home Assistant integration safety and formatting compliance

- Applied YAML/script updates across integration files to satisfy strict linting/formatting while preserving behavior contracts.
- host_check.sh adjusted for safer command handling and lint compliance.
- install/uninstall and sensor/automation YAML files normalized for policy consistency.

### 5. Test suite reinforcement

- Expanded and reformatted Bats test suites for unit/component/e2e consistency and stronger host-check coverage.
- Coverage report badge updated in assets/coverage.svg to 96%.

### 6. Agent and skills scaffolding

- Added project-level Copilot customization files and agent workflow metadata:
  - .github/instructions/project.instructions.md
  - .github/agents/project.agent.md
  - .github/prompts/project.prompt.md
  - AGENTS.md
  - .agent/agents.md
  - .github/copilot-instructions.md
  - .github/skills/README.md
- Refined project skills under .github/skills/* for targeted maintenance tasks.

### 7. Documentation updates

- Updated README.md, docs/Instructions.md, and docs/* to reflect mandatory quality policy, workflow expectations, and safety behavior.
