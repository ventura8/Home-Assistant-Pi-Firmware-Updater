# Home Assistant Pi Firmware Updater v1.0.8 - SonarQube Cloud Coverage Import

CI release. SonarQube Cloud now runs from GitHub Actions instead of Automatic
Analysis, so it imports the kcov coverage report.

**No runtime changes for end users.** Nothing to do on upgrade.

## Highlights

- **Coverage in SonarQube Cloud:** the `sonarqube` job in `test.yml` is live
  and uploads the merged kcov report (93.90%).
- **Manual test runs:** `Run Tests` gains a `workflow_dispatch` trigger. A
  re-run of an old run keeps its original variables; a manual run does not.

## Upgrade

- Update via HACS (or copy `custom_components/pi_firmware_updater/`).
- **No installer re-run required.** No host state changes.

## Validation

- `./tests/run_tests.sh lint` green
- Coverage: 93.90% (>= 90% threshold)
