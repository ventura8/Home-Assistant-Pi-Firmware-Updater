# Home Assistant Pi Firmware Updater v1.0.9 - Exact-Match Host Key Cleanup

Security fix for the installer, plus a dependency refresh.

## Security fix (medium)

A component with write access to `/config/` could plant an `id_rsa.pub` with
a short, common `ssh-rsa` blob prefix. The next `install.sh` run would then
delete unrelated admin keys from the host's `/root/.ssh/authorized_keys`
(port 22222), because cleanup used a substring match.

- `id_rsa.pub` must now match `ssh-keygen -y -f id_rsa`, or setup aborts
  before any host change.
- Blobs shorter than a real key (68 base64 characters) are rejected.
- Host cleanup in `install.sh` and `ssh_wrapper.sh` only removes the managed
  wrapper line and exact key matches. Keys that share a prefix are kept.

## Upgrade

- Update via HACS (or copy `custom_components/pi_firmware_updater/`).
- **Re-run `install.sh`** so the host gets the fixed `ssh_wrapper.sh`.
- If setup reports `id_rsa.pub does not match id_rsa`, check what wrote that
  file. Then delete `/config/.ssh/id_rsa.pub` and re-run `install.sh`.
