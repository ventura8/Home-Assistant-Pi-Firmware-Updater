# Home Assistant Pi Firmware Updater v1.0.7 - Test Image SonarQube Cleanup

Tooling release. Resolves the last 8 SonarQube Cloud issues, all in the
test-only `tests/Dockerfile`. The project now has 0 open issues and 0
security hotspots.

**No runtime changes for end users.** Nothing to do on upgrade.

## Highlights

- **Checksum-verified `ADD`:** pinned tool downloads use
  `ADD --checksum=sha256:...` instead of `curl` + `sha256sum` (`S7026`).
- **Merged build steps:** consecutive `RUN` instructions, including the kcov
  build, are one layer (`S7031`).
- **Narrow `COPY`:** the image copies only `custom_components/` and `tests/`
  instead of the whole build context (`S6470`).
- **Non-root test container:** the image runs as an unprivileged `tester`
  user (`S6471`). CI and the PowerShell runners build it with the host's
  UID/GID so mounted coverage output stays writable.

## Upgrade

- Update via HACS (or copy `custom_components/pi_firmware_updater/`).
- **No installer re-run required.** No host state changes.

## Notes

- Contributors on Linux building the image by hand should pass
  `--build-arg TEST_UID=$(id -u) --build-arg TEST_GID=$(id -g)`. The
  PowerShell runners do this automatically.
- Coverage is unchanged at 93.90%.

## Validation
