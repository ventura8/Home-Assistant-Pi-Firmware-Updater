## Agent Modes

## Explore Mode

Use for architecture discovery, file tracing, and impact analysis.

## Fix Mode

Use `.agent/workflows/fix.md` and `.github/skills/ha-firmware-fix-pass/SKILL.md`.

## YAML Integration Mode

Use `.github/skills/ha-yaml-integration-edits/SKILL.md` for safe Home Assistant YAML edits.

## Host Safety Mode

Use `.github/skills/host-check-update-safety/SKILL.md` for `host_check.sh` logic.

## Installer Maintenance Mode

Use `.github/skills/install-uninstall-script-maintenance/SKILL.md` for install/uninstall changes.

## Test Authoring Mode

Use `.github/skills/bats-kcov-test-authoring/SKILL.md` for Bats and kcov work.

## Release Mode

Use `.github/skills/release-doc-and-badge-update/SKILL.md` for docs and badge updates.
